Create a modern personal portfolio website for a Full-Stack & Mobile Developer named Alejandro Berroterán.

PRIMARY GOAL
The website should help Alejandro attract international freelance clients and remote job opportunities.

POSITIONING
Full-Stack & Mobile Developer.

Main value proposition:
“I design, build and deploy digital products for real businesses.”

The portfolio should communicate that Alejandro can:
1. Build complete digital products from scratch.
2. Improve and modernize existing products.
3. Launch web and mobile applications into production.

LANGUAGE
The primary language should be English.
Include a visible EN / ES language switcher in the navigation.
Design the interface assuming all content will exist in both English and Spanish.

STYLE DIRECTION
Use a clean, premium, modern developer portfolio aesthetic.

Take inspiration from:
- Brittany Chiang for hierarchy, clarity and professional structure.
- Timmy O’Mahony for strong commercial positioning and calls to action.
- Josh Comeau and mxb.dev only for subtle personality and microinteractions.

Do NOT directly copy any existing portfolio.

The design should feel:
- professional
- modern
- technical
- confident
- minimal but not empty
- slightly creative
- suitable for international freelance clients

Avoid:
- overly playful visual design
- excessive gradients
- excessive glassmorphism
- generic SaaS template appearance
- huge amounts of decorative elements
- skill bars
- percentage-based skill ratings
- generic “Hello World” developer clichés

VISUAL SYSTEM
Use a dark or dark-neutral base with strong contrast.
Typography should be large, modern and highly readable.
Use generous spacing.
Cards and project sections should feel editorial rather than like a dashboard.

Use a restrained accent color.
Use subtle borders, hover states and motion.

The project screenshots should be the main visual elements.

DESKTOP FIRST
Create the main design at approximately 1440px width.
Also create a mobile version around 390px width.
